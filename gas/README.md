# 「みんなの結果」を全員分で集計する設定（約5分）

設定しない場合は、各スマホ／PCの中だけで集計されます。
QRコードでたくさんの人のスマホから参加してもらうなら、この設定をしてください。

1. Googleスプレッドシートを新しく作る（名前は自由。例：NEXT ROLE 16 集計）
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードを全部消して、`Code.gs` の中身を貼り付けて保存
4. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」→ Googleアカウントの許可を進める → 表示された **ウェブアプリのURL**（…/exec）をコピー
6. `js/config.js` の `STATS_URL: ''` の '' の中にURLを貼る

```js
const CONFIG = {
  STATS_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
};
```

- 結果はスプレッドシートの `results` シートに1行ずつ追加されます（日時・タイプ・各軸の割合のみ）。
- 本番前にテスト記録を消したいときは、シートの2行目以降を削除するだけでOKです。
